# CraftVPN

CraftVPN은 [clash-verge-rev](https://github.com/clash-verge-rev/clash-verge-rev)의 수정판입니다. 수정일은 **2026-11-10**입니다. 라이선스는 **GPL-3.0**이며 원래 [LICENSE](../LICENSE)와 소스의 저작권 표시를 유지합니다. [NOTICE](../NOTICE)를 보세요.

Clash Verge, Clash Verge Rev, clash-verge-rev의 공식 릴리스가 아니고 그 프로젝트와 제휴하지 않습니다. TrafCraft LLC의 Android 앱 “Craft VPN”도 아닙니다.

소스: <https://github.com/ma906584241/clash-verge-rev>

Windows에서 제품 이름, 창 제목, 트레이, 설치 프로그램 이름은 **CraftVPN**입니다. 앱 ID는 `io.github.ma906584241.craftvpn`이고 딥 링크는 `craftvpn://`입니다. 코어는 오픈 소스 [mihomo](https://github.com/MetaCubeX/mihomo)입니다. 제품 이름에 mihomo는 들어 있지 않습니다.

앱 내부 업데이트는 꺼져 있으며 Clash Verge 업데이트 서버에 접속하지 않습니다. 아이콘은 나중에 바꿀 수 있는 원본 자리표시자입니다.

영어 설명은 [README_en.md](./README_en.md)에 있습니다. 라이선스: GPL-3.0.
