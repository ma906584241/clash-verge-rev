No es una publicación oficial de Clash Verge, Clash Verge Rev ni clash-verge-rev, y no está afiliada a esos proyectos. Tampoco es la aplicación Android “Craft VPN” de TrafCraft LLC.

Código y notas: <https://github.com/ma906584241/clash-verge-rev>

En Windows el nombre de producto, el título de la ventana, la bandeja y el instalador dicen **CraftVPN**. El identificador es `io.github.ma906584241.craftvpn`. El esquema de enlace es `craftvpn://`. El núcleo es el [mihomo](https://github.com/MetaCubeX/mihomo) de código abierto. El nombre del producto no incluye mihomo.

Las actualizaciones dentro de la aplicación están desactivadas y no consultan los servidores de actualización de Clash Verge. Los iconos son marcadores de posición originales.
