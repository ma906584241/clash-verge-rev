# CraftVPN

CraftVPN — изменённая версия [clash-verge-rev](https://github.com/clash-verge-rev/clash-verge-rev). Дата изменения: **2026-11-10**. Лицензия по-прежнему **GPL-3.0**. Файл [LICENSE](../LICENSE) и исходные уведомления об авторских правах сохранены. См. [NOTICE](../NOTICE).

Это не официальный выпуск Clash Verge, Clash Verge Rev или clash-verge-rev, и проект с ними не связан. Это также не Android-приложение «Craft VPN» компании TrafCraft LLC.

Исходный код: <https://github.com/ma906584241/clash-verge-rev>

В Windows имя продукта, заголовок окна, подсказка в трее и установщик — **CraftVPN**. Идентификатор приложения: `io.github.ma906584241.craftvpn`. Схема ссылок: `craftvpn://`. Ядро — открытый [mihomo](https://github.com/MetaCubeX/mihomo). В имени продукта нет mihomo.

Встроенные обновления выключены и не обращаются к серверам обновлений Clash Verge. Значки — временные оригинальные заготовки.
