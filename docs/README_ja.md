ソースと説明: <https://github.com/ma906584241/clash-verge-rev>

Windows では製品名、ウィンドウタイトル、トレイ、インストーラー名が **CraftVPN** です。アプリケーション ID は `io.github.ma906584241.craftvpn`、ディープリンクは `craftvpn://` です。中核はオープンソースの [mihomo](https://github.com/MetaCubeX/mihomo) です。製品名に mihomo は含まれません。

アプリ内更新は無効で、Clash Verge の更新サーバーには接続しません。アイコンは後から差し替えられる仮のオリジナルです。
